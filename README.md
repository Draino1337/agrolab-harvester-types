# Виды комбайнов — Агролаб

Учебный сайт по видам сельскохозяйственных комбайнов: четыре соответствия и две производственные ситуации. Перед каждым пунктом есть фотография нужного вида техники. Самопроверка: до 6 баллов, подсветка ошибок, повторная попытка и печать результата.

Блок рефлексии удалён. QR-код ведёт на опубликованный сайт.

## Запуск

Открыть `index.html` в браузере. Для GitHub Pages: ветка `main`, каталог `/`. Сайт не требует сборки, внешних скриптов и ключей API. Ответы не отправляются на сервер.
